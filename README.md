# 🏦 Bank Management System in C

A simple console-based **Bank Management System** written in **C language**.  
This program allows users to create, view, and manage bank accounts using basic file handling.  
All data is stored in a **text file (`record.txt`)** for persistence.

---

## 📖 Features

✅ **Password-Protected Login**  
Only authorized users can access the system.

✅ **Create New Account**  
Add customer details like name, DOB, address, and initial deposit.

✅ **View All Customer Accounts**  
Display a list of all existing accounts with basic details.

✅ **Data Storage in Text File**  
Customer records are saved in a human-readable file `record.txt`.

✅ **Cross-Platform Compatibility**  
Works on both **Windows** and **Linux/macOS** terminals.

---

## 🧩 Technologies Used

- **Language:** C  
- **File Handling:** Text-based storage  
- **Compiler:** GCC / MinGW  
- **IDE (Optional):** Code::Blocks, Dev-C++, Visual Studio Code
